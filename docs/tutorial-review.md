# 用户提供的预约教程核对

来源：https://xhslink.cn/o/1JawF9p1p94

笔记：美宝Jimmy在西班牙《🇪🇸预约cita的教程来啦》，2025-12-19，视频约 1 分 26 秒。以下来自逐段查看的视频画面，不把评论当官方规定。

- 约 00:24：选择省份。
- 约 00:40：Madrid，任意办公室，选择按指纹业务。视频页面经过英文翻译；本项目使用 Barcelona 和西班牙语。
- 约 00:56：填写 NIE、姓名、国籍。
- 约 01:02：后续页面出现具体办公室下拉菜单，URL 路径为 acCitar。
- 约 01:09：联系方式表单，电话、邮箱、重复邮箱；路径 acVerFormulario。
- 约 01:18：日期和时段表、图形验证码；路径 acOfertarCita。列表同时包含 BUSY 和 FREE 状态，不能把整个日历页或任意按钮都认定为号源。
- 约 01:24：视频结尾。此次查看的画面不能验证成功预约回执或巴塞罗那当前页面 DOM。

实现影响：保持首页公告与业务结果分离；未知页面通知人工核实；联系方式和日期页可以触发待核实提醒，但不直接标记 AVAILABLE。不根据视频截图猜 CSS 选择器，不自动处理验证码，不自动提交预约。

用户最新要求是有号邮件提醒。已提供观察模式用于等待真实页面变化；正式精确有号识别仍需核实当前官网可选时段的结构。观察模式清空未经验证的正向选择器，避免错误有号通知。
